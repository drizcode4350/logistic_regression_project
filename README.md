Logistic Regression Projects

This repository contains two beginner-friendly Logistic Regression machine learning projects implemented in Python using Google Colab. The projects demonstrate the complete machine learning workflow, from data preprocessing to model evaluation, using real-world placement datasets.

📂 Repository Structure

logistic_regression_project/
│── project1.ipynb                  # Logistic Regression Project 1
│── project2.ipynb                  # Logistic Regression Project 2
│── placement.csv                   # Original dataset
│── modified_placement_data.csv     # Preprocessed dataset
│── README.md

🎯 Objectives

Understand the working of Logistic Regression.

Perform data preprocessing and exploratory data analysis (EDA).

Build and evaluate a binary classification model.

Learn the end-to-end machine learning pipeline.


📋 Workflow

Each notebook follows the standard machine learning pipeline:

1. Data Loading


2. Data Preprocessing


3. Exploratory Data Analysis (EDA)


4. Feature Selection


5. Input and Output Separation


6. Feature Scaling


7. Train-Test Split


8. Model Training using Logistic Regression


9. Model Evaluation


10. Prediction on New Data

🚀 How to Run

1. Clone the repository:

git clone https://github.com/drizcode4350/logistic_regression_project.git


2. Open either notebook in Google Colab or Jupyter Notebook.


3. Install the required libraries (if needed):

pip install numpy pandas matplotlib scikit-learn


4. Run all cells sequentially.
